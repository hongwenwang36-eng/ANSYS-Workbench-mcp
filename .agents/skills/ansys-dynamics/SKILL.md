name: ansys-dynamics
description: 进行模态、预应力模态、谐响应、瞬态、响应谱及随机振动分析。
---

核对刚度、质量、约束、坐标系、阻尼模型和激励方向。Workbench 中按类型创建 Modal、Harmonic Response、Transient Structural、Response Spectrum 或 Random Vibration 系统，也可用 `run_mapdl_input` 读取 APDL。依赖模态结果的分析先计算并扩展所需振型，保持节点及自由度一致。

| 分析 | 求解设置与验收 |
|---|---|
| 模态、预应力模态 | 明确自由或约束模态、频带和预载步，确认预应力状态传入。记录刚体模态、频率、振型以及目标方向有效质量。振型幅值具有归一化尺度。 |
| 谐响应 | 明确激励为力还是基底加速度、频率单位、振幅与相位。共振附近细化频率步，记录复响应的幅值和相位。 |
| 瞬态 | 核对初值、脉冲持续时间、载荷插值与积分时间步，比较缩小时间步后的峰值和发生时间。 |
| 响应谱 | 记录谱的加速度/速度/位移定义、单位、阻尼及模态组合方式。交付组合峰值与所用方向。 |
| 随机振动 | 核对 PSD 量纲、单/双边定义、频带和相关性，按用户指定输出 PSD、RMS 或特定 sigma 倍数。 |

报告采用的模态阶数和频带覆盖；用有解析频率或传递函数的小模型核查峰频、幅值或方差。导出频率/时程 CSV、振型或响应云图。


MAPDL 响应谱的组合结果在 /POST1 执行求解生成的作业名 .mcom 文件读取。PSD 的位移 1σ 结果需要选择相应结果集，配套基准使用 SET,3,1。先列出结果集及其含义再提取，避免 SET,LAST 选中另一种统计量。

配套可复跑基准与适用范围见 [examples/mechanics](../../../examples/mechanics/README.md)。工作目录以仓库根目录为准，运行产物保存到 runs。

恒幅谐响应扫频在 APDL 设置 KBC,1，核对每个频率点的实际载荷。复数结果的结果集数可包含实部与虚部，导出时明确对应频率和复分量，合成幅值与相位后再比较解析值。
